# Keep recommendations broader than tutorial coverage

The user wants multi-tool recommendations to remain part of the core prototype even while only OpenLaw receives complete tutorial coverage. Keep high-level tool explanations, pros/cons, and explicit coverage labels; enable visual tutorial generation only where reviewed assets exist. This preserves the product concept without building training libraries or integrations for every recommended technology.

This resolves the open UI question in ADR 0006: OpenLaw-first limits tutorial implementation, not the recommendation catalog. Recommendations still need to be relevant to the scenario. Cross-tool operational workflows remain deferred.
