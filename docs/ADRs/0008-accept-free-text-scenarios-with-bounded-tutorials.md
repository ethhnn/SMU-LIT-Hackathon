# Accept free-text scenarios while keeping tutorials bounded

The specification had narrowed the whole product to a prepared OpenLaw lesson. The user's correction restores free-text non-confidential Training objectives, optional example scenarios, and model-backed recommendations from a curated tool catalog. Recommendation selection and explanations must adapt to the scenario. This preserves scenario-driven discovery without implementing tutorial assets for every tool.

OpenLaw remains the first renderable tutorial demonstration, limited to its reviewed Search-field scene. Other recommended tools provide high-level grouped contextual text and explicit coverage limits. Dynamic recommendations do not authorize arbitrary operational workflows or cross-tool handoffs; a shared visual tutorial remains grounded in an exact manually curated Lesson Plan and its reviewed assets.

This supersedes mandatory prepared-scenario wording in earlier planning documents. Synthetic/generic content restrictions, explicit video requests, and the minimal media pipeline remain in force. It extends ADR 0007 by making recommendation behavior dynamic rather than merely retaining multiple catalog cards.
