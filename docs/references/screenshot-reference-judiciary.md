# Judiciary.gov.sg / SG Courts screenshot reference

Source folder: `Screenshots/JudiciaryGovScreenshots/`

## Shared controls

Unless cropped out, the site header contains the SG Courts logo/home link and **Who we are**, **Discover the courts**, **Hearing list**, **Judgments**, **Self-help guides** with a dropdown chevron, **News and Resources**, **Services**, **Contact**, and a square magnifier **Search** button. The government-site banner includes **How to identify** with a dropdown chevron. Long pages show a fixed **Help us improve** feedback tab and a square up-chevron **Back to top** button. Many page footers include **Facebook**, **X**, **Email**, and **Print** sharing actions. Breadcrumbs begin with **Home**.

## Find a Hearing shared controls and filters

All six Find a Hearing captures use the same search form unless the crop excludes part of it:

- free-text field: **Search by party name, case no, judicial officer or law firm**;
- maroon magnifier **Search** button;
- dropdown filters: **Court**, **Law firm**, **Judge/Judicial officer**, **Hearing Type**, and **Date**;
- court result tabs: **All courts** (selected in these captures), **Supreme Court**, **State Courts**, and **Family Justice Courts**;
- **Results per page** dropdown set to 10 and a **Sort By** dropdown.
