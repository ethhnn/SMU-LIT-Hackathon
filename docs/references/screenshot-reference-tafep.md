# TAFEP screenshot reference

Source folder: `Screenshots/TAFEPScreenshots/`  
Image count: 21

## Shared controls

Unless cropped out, the TAFEP header contains the TAFEP logo/home link; **About Us**, **Contact Us**, **eServices**, **Events and Workshops**, and **Media**; a site-search text field with magnifier; and the second-row links **Employment Practices**, **Tripartite Guidelines**, **Workplace Fairness**, and **Resources**. A teal alert/advisory launcher is fixed at the right edge, and a round up-chevron **Back to top** button appears on longer pages. Breadcrumbs use a Home icon and chevrons. Some captures include a scam-advisory banner with **Close** and **X** controls.

Cards, article titles, underlined text, and arrow rows described below are visible navigation links. Shared header controls are not repeated in every row.
