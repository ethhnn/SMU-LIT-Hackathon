## How to use these references

Use the exact image name to identify a screenshot before reasoning about it. Read the website's shared-controls section together with the image-specific row. Descriptions record what is visibly present; they do not prove that an interaction was successfully tested.

The generated files under `public/assets/screenshots/` are build outputs. Keep these Markdown files as the human-reviewed source and generate machine-readable metadata separately.
